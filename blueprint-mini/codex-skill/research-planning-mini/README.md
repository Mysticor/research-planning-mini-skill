# Research Planning Mini 使用
用 `$research-planning-mini` 从实际研究目录开始或继续。与原版共用 state、冻结和交接格式；同一研究一次只用一个版本编辑。
Python 需 3.11+，并安装仓库 requirements.txt；`scripts/researchctl.py --help` 查看命令，check/package 保留证据要求。
当前步骤按需读取 references；resume.md 是导航，不是事实母本。
模块 vendor 包含固定依赖，共享状态库位于仓库根目录 workflow-contract；迁移时保留仓库结构。
本版精简运行指令，真实下载与远程上下文压缩稳定性未验收。
