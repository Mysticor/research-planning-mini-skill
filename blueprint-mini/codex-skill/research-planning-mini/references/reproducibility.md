# Reproducibility and integrity
Record source-code path/commit or content hash, environment/dependency versions,
seeds/config, data version/preprocessing, checkpoint, analysis scripts, figure
source data and relevant hardware. Link each key result to its raw source and
analysis; checksum files at capture and verification. Preserve revisions.
Review extraction/synthesis must be reproducible from query logs, screening,
source locators and extraction tables instead of fictitious model checkpoints.

Only relevant human/animal ethics, privacy, sensitive data, licences for data,
software/models/images, dataset terms, confidentiality, conflicts and known
authorship facts are recorded. Never invent approvals. Internal evidence access
and publication permission differ. Restricted inputs must be represented by an
explicit access protocol; if central handoff evidence cannot be included or
accessed, readiness is blocked rather than labelled self-contained.
