# Readiness gate
READY: complete actual evidence, central claims supported, all key numbers traced,
statistics complete or justified N/A, limitations, chosen route, selected or explicit
target-agnostic journal, canon, verified important references, current novelty and
journal refresh, asset provenance, no critical contradictions, no placeholders,
no invented citations, no hypothesis disguised as finding; Gate F recorded under the shared AUTO/user-decision rule.
READY_WITH_AUTHOR_CHECKS: only noncentral author facts remain, individually listed
with impact. Missing central evidence, stats needed for a central inference,
permissions required for essential evidence or unresolved critical contradictions
always BLOCKED. User willingness to write does not override missing evidence.

researchctl check validates schemas, links, hashes, records and gates; Agent must
also inspect underlying evidence, appropriate methods, citation correctness and
scientific adequacy. Neither a boolean nor passing code proves truth. Record that
review with artifact checksum in state.scientific_review. Any change to claims,
results, references or design invalidates review/approval via fingerprint.
MOCK projects can yield a complete test bundle marked MOCK, never a production
READY_FOR_NATURE_WRITING marker. Handoff refuses nonempty destinations.
