# Journal as a design constraint
Compare STRETCH, PRIMARY and BACKUP using current official scope/article types,
audience, recent relevant exemplars, novelty and method expectations, real-world
validation, data/code rules, length/display/SI limits and submission requirements.
APC/publication model is checked if it affects this user's decision. Log exact
source URL, access date and relevant requirement, not remembered rules. Separate
explicit policy from inference from exemplars. Derive design implications before
experiments. Record a primary target or target-agnostic at Gate C under the shared AUTO rule; ask only for materially different choices.

Refresh primary guidance at handoff, including scope, type, latest limits, data/code
and submission requirements; document changes since design. Target-agnostic needs
an explicit dated record of that choice and general obligations; do not invent a
journal just to pass the check. Archived local profiles are starting points only.
