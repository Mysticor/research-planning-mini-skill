# Handoff contract (version 1)
Output MANUSCRIPT_HANDOFF only after check. It contains README, readiness.json,
the 18 numbered artifacts mapped in manifest.yaml, references.bib, the frozen
blueprint, actual dossier, decision/deviation/failure logs, source paper cards,
search/refresh logs, experiment protocols/logs, reproducibility records and all
referenced source/analysis/asset files in an included research_blueprint/ snapshot.
Keep project-relative links resolvable within the package, verify hashes, and never
rely on a chat, absolute local paths or symlinks outside the package. Do not include
credentials. Record permission/access limitations explicitly; blocked essentials
prevent READY. Existing packages are immutable; export to a new empty version path.

The numbered materials cover target journal; story FACTS (not Introduction);
actual claims/numbers/methods/data/statistics; literature canon and verified claim
references; legal exemplar patterns; asset and table-ready inventories; potential
SI evidence; limitations; terminology; ethics/data/code availability; unresolved
items and truly author-only questions. Templates are prompts, not completed facts.
Carry the relevant library beyond the core shortlist. In the existing literature
canon and source records, distinguish candidate, read and verified status, source
locations, likely evidentiary roles and remaining coverage gaps. Keep screened-only
candidates in library notes/cards, not the verified claim-reference map or required
reference-verification rows; retain the existing checker requirements. Preserve any
user-supplied citation baseline/target in the handoff notes without recalculating it.
Library size is not a promise of final cited count; Stage 2 selects actual uses and
verifies sources at use. Do not present screened-only candidates as verified support.

For the core literature set, 08_literature_canon links the search/screening criteria,
actual unique candidate/screened/selected/downloaded/deeply-read counts, selected and
near-selected paper IDs with reasons, full-text originals and reading notes, and
the resulting cross-paper evidence/gap/content synthesis. Preserve exclusions,
contradictions, replacements and outstanding manual-download items. Keep the
scientific core distinct from journal-format comparators and mark shared paper IDs;
mere citation counts or 20 abstract summaries do not satisfy the deep-reading target.

For journal comparators, carry the two groups from [journal strategy](journal-strategy.md)
in the existing 01 target profile and 10 exemplar records: selection rationale,
paper IDs/groups, full-text paths/hashes, per-paper measures and source locators,
group statistics, actual downloaded/measured counts and remaining gaps. Include
the referenced originals in the self-contained snapshot so Stage 2 can reuse and
complete this work without downloading the same papers again. A provisional sample
remains visibly unfinished even if package checks pass. Comparator status alone
does not establish scientific support or require citation; retain the distinction
between candidates, read sources and verified claim uses.

manuscript-writing should start by reading README → readiness → claims/results → actual
fact sheets → canon/references → assets/limits, then verify paths and build its own
Manuscript Blueprint. It owns paragraph/Results order, figure/table numbers, main
vs SI choices and final wording. research-planning never writes Abstract,
Introduction, Results, Discussion or Conclusion prose. Factual notes/specs are allowed.
If the installed manuscript-writing has no automated package parser, provide this
explicit reading contract. Do not claim an upstream machine interface exists.
