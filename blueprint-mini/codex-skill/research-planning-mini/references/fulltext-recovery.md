# 全文获取与接续

对已选定的论文获取正文；沿用用户已有正文/SI选择。公开全文补查使用本 Skill 的 `scripts/acquire_fulltext.py`，原 `nature-downloader` 继续负责已配置出版商API、机构浏览器与SI。两者互补，不修改固定vendor。

```bash
python scripts/acquire_fulltext.py selected-papers.json --out <project>/literature/fulltext --limit 30
```

使用已安装依赖的 Python 3.11+；依赖 requests、beautifulsoup4、PyMuPDF。输入可为论文数组或含 records/results 的JSON。必须保留 DOI、title，以及检索中的 source_urls、pdf_urls、locations 和 provenance_records。只传DOI会丢失已知仓储/全文地址。脚本不做论文遴选；输入数量超出limit时其余条目尚未处理，不能宣称整批完成。

先复用已核验文件与用户放入输出目录 `manual/` 的PDF。确定30篇核心清单（或用户确认的调整数量）后，凡带知网来源的入选论文，立即汇总告知用户手动下载：题名、作者、年份、DOI（无则明确无）、知网详情链接及项目实际 `manual/` 接收目录。不自动尝试知网下载，不要求为下载替换已选论文；已有核验原件直接复用。脚本保留 `cnki_manual_download` 缺口及详情链接，导入时须保留来源/provenance，不用只有DOI的清单丢掉渠道信息。没有新缺口不重复催交；批量列清单后继续其他可独立工作。

其余论文已有可用官方PDF入口时直接使用；没有或入口失败时，若可控制浏览器可用，先按下述Nomad规则检查可见入口。没有可用浏览器/入口或尝试失败则保留原机构、开放获取及手动路线。公开补查脚本本身不驱动浏览器或Nomad，调用它不表示已经检查过扩展。公开路线再尝试已知来源；按精确DOI补查OpenAlex、Europe PMC、Unpaywall及出版社入口，从文章页面的PDF元数据/链接获取原文。不开启来源不明镜像，不猜测URL，不自动解决验证挑战。Unpaywall读取环境变量 UNPAYWALL_EMAIL 或 `~/.config/lit-dl/settings.json` 中的 open_access.contact_email；没有真实邮箱则记为未配置，不伪造。用户提供后配置一次，邮箱不写入Skill或公开仓库。

临时网络错误、429和5xx最多尝试3次并退避；Retry-After超过30秒则留待后续，不持续等待或撞限流。403、登录或验证页面记录为访问受限，转机构/用户路径；不当作全文不存在。每篇默认最多访问16个候选，触限表示待续而非没有全文，模型检查record.json后可增加明确范围或补充链接。不要为完成下载数量替换科学上重要的论文。

每篇以DOI/题名哈希建目录，保存原件、来源、版本（无法确定则unknown）、SHA256及逐次失败记录；逐篇写manifest，可复用成功项继续。PDF需可解析、页数非零且题名/DOI与内容匹配；扫描件或匹配不明的原件需要人工核验/OCR，不计自动成功。完整HTML/XML与PDF分开统计；结构与身份自动通过只表示取得候选正文，进入精读前仍核对正文是否完整、图表及必要附件是否可见。不得把摘要页、验证页、题录或自动提取当作精读完成。

## 浏览器入口与 LibKey Nomad

使用实际可控制、已启用Nomad的浏览器（优先已有Chrome会话），在目标论文页核对标题/DOI后查看页面可见的Nomad下载或访问入口；不凭扩展安装状态声称链接存在，不猜隐藏接口或下载URL。已有可用官方PDF入口无需绕行Nomad。复用已有用户所属机构授权会话；Nomad只帮助定位入口，不替代机构订阅和认证，不保证全文可得。没有配置/看不到入口时记录未使用，不为此卡住整批或擅自安装插件。

点击实际可见入口，登录、MFA或安全验证交给用户完成，保存当前论文和页面待续；用户处理前暂停该浏览器任务，其他独立条目可继续。不得读取、导出Cookie/token/密码或将会话传给命令行。入口失败后保留原因，沿用原机构、合法开放获取或用户手动/Zotero路径，不循环点击验证。页面入口及授权流的说明参考 https://thirdiron.com/where-to-use-libkey/；实际行为以当前页面为准。

浏览器下载先放项目暂存/manual目录，使用同一校验流程检查文件真实类型、可解析性、题名、DOI（没有DOI则组合核对题名/作者/年份/来源）、版本和内容完整性，排除摘要页、登录页、附件冒充正文和截断PDF。自动身份校验仅是初检：仍须人工/模型实际检查正文、图表、页数连续性及版本；无法确认记待核验，不能直接归档为最终核验全文。确认后按paper_id归档原件与哈希，在已有记录中保留实际入口、获取方式/时间和检查结论；版本未知如实保留。浏览器成功下载不代表已精读。

公开路线未取得正文时，按已有授权调用nature-downloader或可控制的已登录浏览器走机构路线。先确认浏览器可控且认证会话真实有效，再让用户登录；登录/MFA由用户完成，不导出cookie或索取密码。机构路径失败后交付missing.json清单：题名、DOI、官方入口、实际尝试原因和manual接收目录；将机构尝试追加到项目记录中。用户放入PDF后重跑同一命令，自动核验匹配并接续；版本与内容完整性仍按精读规则确认。

验证状态不自动改写科学证据账本、精读状态或写作交接。获取完成后按既有paper_id关联原件及哈希，保留缺失图表/SI、版本差异和不能闭合的判断。
