# 可选的网页与本地协作

默认在当前可用环境完成工作。只有用户选择跨环境协作、收到交接包或当前步骤缺少必要工具时才启用本规则；全程 Codex 不额外要求 ZIP、切换模型、人工搬运或新审批。原阶段、科学 Gate、分批停止与代表图确认规则不变。审稿mini继续在 Codex 的隔离 Agent 流程完成，不在网页模拟双审。

## 开始与恢复

根据实际工具判断能力，不凭产品名称推断。首次进入或换环境时，仅检查当前步骤需要的文件读写/ZIP、脚本执行、联网/API、PDF文本/图像查看、本地授权浏览器、Python/R/TeX与依赖。记录“可用/不可用/未验证”及简短依据到现有 resume，不建立第二份研究状态；环境未变化不重复探测。网页工具未知时先做小范围读写/查看验证，不能虚构执行结果。

GitHub链接是入口而非安装证明：确认读到本步骤的 SKILL.md、引用规则、脚本和依赖，记录实际版本。只能读首页时请用户上传完整发布包，不宣称已加载。使用当前实际可用且满足依赖的Python；不照抄其他环境的绝对路径。缺少共享契约或锁定vendor时不要用猜测补齐。

恢复先读现有 state、resume、manifest 和当前任务的证据。异机绝对路径不可直接使用；按包内相对路径定位。涉及 canonical/版本迁移使用原契约工具核验，不全局替换文件中的路径、不重建研究项目。工具无法运行时可继续不依赖它的讨论/草稿，但记录校验待完成，不能宣称 Gate READY。

## 模型建议（可选，不自动切换）

按工作难度选择当前账号可用模型，不预设型号，不自动切换：检索、去重和计数优先确定性脚本；摘要疑难判断、全文证据综合和正文写作使用可靠的通用推理模型；创新性、关键设计和科学争议按需采用更强推理模型。用户或宿主负责实际路由，用户指定优先。审稿的独立性不因节省费用而降低；模型建议不构成效果或费用保证。只读取当前批次必要材料，不省略原文核验。

## 每批交付

协作模式下每个约定步骤/批次结束：保存现有状态和决定，简报成果、实际阅读/获取数量、缺口、待确认事项、下一步与建议模型，并交付ZIP及接续提示词。全程本地模式继续原有保存/报告方式。

工作包包含截至当前的全部工作成果、原状态/manifest/resume、必要证据与来源、代码和下一步提示词。不要包含聊天历史、缓存、无关日志、Cookie、密钥、.env或浏览器配置。大原始PDF/数据可作为独立稳定资料包；在resume列出精确版本、文件清单及校验值，明确“需要资料包”，不得声称工作包单独完整。缺失证据仍为缺失。

接续提示词写清：项目/当前步骤、必读文件、任务范围、所需能力、返回文件与格式、真实验证要求、停止点。引用包内相对路径；不把科学计划写成已取得的结果。Skill版本写入resume，任务数据包不自动复制整个Skill/vendor。

共享 `portable_bundle.py` 仅传输校验，不更改研究状态、不认证科学质量。先列全相关工作文件到UTF-8清单（一行一个项目相对路径），排除文件必须在resume解释；人工检查清单与文本无凭据。路径过滤不能保证内容无秘密。输出ZIP放项目之外。

```text
python portable_bundle.py pack PROJECT --files files.txt --request NEXT.md --out step-01.zip
python portable_bundle.py verify step-01.zip
# 返回本地任务成果时携带收到包的bundle_id；接收者核对
python portable_bundle.py pack RETURN_PROJECT --files files.txt --request NEXT.md --base-id RECEIVED_ID --out return-01.zip
python portable_bundle.py verify return-01.zip --expected-base RECEIVED_ID
```

程序位于本共享目录。文件列表覆盖所有需要交付的文件，不支持目录/通配符隐式打包。ZIP中的 `bundle.json` 保存内容指纹和base_id，`NEXT.md`保存提示词，`project/`保存原相对布局。SHA256只能检测意外漂移，不能证明作者身份或科学正确性。没有执行/打包工具时输出可保存的文本与缺失附件清单，明确尚未生成ZIP，不造下载链接。

## 本地任务与回传

网页遇到必须使用本地登录浏览器、Zotero、特定绘图后端或TeX时，先完成可独立工作，再交付范围明确的任务包。检索任务要包含检索式、时间/文类、完整摘要等字段、渠道统计与失败记录要求；绘图任务含现有Brief、真实数据、参考图定位、后端与成图检查要求；排版任务含冻结审后稿、全部资产和模板/编译要求。没有必要本地化的工作不外包。

本地只完成指定任务，回传原始结果、衍生成果及实际执行/失败报告；需要用户登录时由用户在本地完成，不传输会话。排版仍须编译、逐页视觉核验、内容核验及独立源码包编译，缺少工具就保持未完成。

接收先verify，再在新的暂存目录检查内容；不自动解压覆盖现有项目。核对project身份（原manifest）、收到任务版本、文件清单、未完成事项和证据真实性；本地母版有新修改则先比较差异，不能直接覆盖。相同base_id不代表母版没有变化。采用成果后由原阶段工具更新状态和核验；只收到摘要/全文不等于已经筛读/精读。

同一项目同一时刻只保留一个活动编辑端。审稿前把完整冻结稿和证据交回Codex，沿用现有审稿流程。收到审后交接再进入排版；工作ZIP不能代替原正式阶段交接包。
